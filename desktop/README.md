# Evergreen Desktop

This directory is reserved for the first-party desktop experience.

The initial ISO uses XFCE as a dependable graphical baseline so that we can validate boot, display, input and networking before writing a replacement shell.

The Evergreen desktop will be developed as a separate, testable application layer. Its initial design goals are:

- a consistent Evergreen visual language;
- integrated launcher, panel and window-management experience;
- accessible keyboard navigation;
- sensible defaults and restrained visual effects;
- clear separation between the shell and underlying Linux services.

No custom compositor or window manager is being claimed at this stage.
