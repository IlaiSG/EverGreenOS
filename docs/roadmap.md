# EverGreenOS Roadmap

## Milestone 1 — Bootable foundation
- [ ] Configure Debian live-build for amd64.
- [ ] Build a live ISO with GitHub Actions.
- [ ] Boot the ISO in browser-accessible QEMU.
- [ ] Verify boot, display, keyboard, networking and shutdown.

## Milestone 2 — Evergreen desktop
- [ ] Select and configure the initial desktop environment.
- [ ] Add Evergreen branding, wallpaper and icons.
- [ ] Review default applications and system settings.

## Milestone 3 — Installation and hardware
- [ ] Create an installation path.
- [ ] Test on physical AMD64 PCs.
- [ ] Document supported hardware and known limitations.

Early development: no bootable image has been produced yet.
